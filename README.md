##  **功能**


#### **动作解析**
*   Live2D → T-Code: 将模型的参数精准映射到硬件轴向。
*  动态映射: 为 SR6 设备提供全面的动态映射支持。

#### **数据处理**
*   实时处理: 通过自定义的倍率和偏移实现精细化控制。
*   全局平滑: 使用线性插值算法过滤动画抖动，保护硬件设备.
